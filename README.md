# Словарь — PWA для iPhone

Все файлы должны лежать в одной папке. Ничего собирать не нужно.

| Файл | Зачем |
|---|---|
| `index.html` | само приложение |
| `words.json` | ваш словарь — единственный файл, который вы правите регулярно |
| `sw.js` | офлайн-режим |
| `manifest.webmanifest` | имя и иконка на экране «Домой» |
| `icon-180/192/512.png` | иконки |

## Публикация на GitHub Pages

1. Заведите репозиторий на github.com, например `dict`. Сделайте его публичным.
2. Кнопка **Add file → Upload files**, перетащите все файлы из этой папки, нажмите **Commit changes**.
3. **Settings → Pages**. В разделе *Build and deployment* выберите Source: **Deploy from a branch**, ветка **main**, папка **/ (root)**. Сохраните.
4. Через минуту-две там же появится адрес вида `https://ваш-логин.github.io/dict/`.

Альтернатива без Git: зайти на app.netlify.com, вкладка **Deploys**, перетащить папку в область Drag and drop. Адрес выдаётся сразу.

## Установка на iPhone

1. Откройте адрес **в Safari** (не в Chrome — там пункта меню не будет).
2. Кнопка «Поделиться» → **На экран «Домой»** → Добавить.
3. Запустите с иконки. Адресной строки не будет, в авиарежиме словарь тоже работает.

## Как добавлять слова

Правьте `words.json`. Формат одной статьи:

```json
{
  "w": "слово",
  "ipa": "/транскрипция/",
  "pos": "сущ.",
  "tr": "перевод",
  "def": "определение",
  "ex": "пример употребления"
}
```

Обязательны только `w` и `tr`, остальное можно опустить. Записи разделяются запятыми, после последней запятой быть не должно — это самая частая ошибка. Проверить файл можно на jsonlint.com.

Сортировка по алфавиту и буквенный указатель справа строятся автоматически — порядок записей в файле не важен.

**Важно:** после каждой правки меняйте номер версии в первой строке `sw.js` (`dict-v1` → `dict-v2`). Иначе iPhone продолжит показывать сохранённую старую копию.

## Проверка на компьютере

Двойной клик по `index.html` не сработает: браузер блокирует `fetch` на `file://`. Запустите локальный сервер из этой папки:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

## Что умеет приложение

- поиск по слову и по переводу, с подсветкой совпадения;
- буквенный указатель справа — вырубные закладки, как в бумажном словаре;
- колонтитул сверху показывает первое и последнее слово на экране;
- тап по статье раскрывает определение и пример;
- кнопка «Наугад» для повторения;
- тёмная тема по системной настройке.
