# Читалка

Чтение адаптированных английских книг: тап по слову — перевод предложения целиком (то есть по смыслу, а не по словарю), транскрипция, произношение и кнопка «в словарь». Из накопленных слов собираются тесты с интервальным повторением.

Всё работает без сервера: обычная статика для GitHub Pages, данные лежат в браузере.

## Публикация

1. Создай репозиторий, например `reader`, и залей туда все файлы из этой папки (не саму папку, а её содержимое).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://keannieaux.github.io/reader/`.

На iPhone: открыть в Safari → «Поделиться» → «На экран „Домой“». Дальше приложение запускается на весь экран и работает офлайн (кроме перевода — ему нужна сеть).

Если хочется положить рядом со словарём в репозиторий `dict`, скопируй файлы в подпапку `reader/` — адрес будет `.../dict/reader/`.

## Как добавить свои книги

В комплекте уже лежат шесть распознанных книг. Свою добавляют так.

В приложении: **Книги → Добавить книгу**. Вставляешь название, название главы и текст. Абзацы разделяются пустой строкой. Дальше **Добавить главу** для каждой следующей.

Так книга живёт только в этом браузере. Чтобы она открывалась на всех устройствах и не пропала при чистке Safari:

1. Открой книгу → **Скачать книгу файлом** — получишь `<id>.json`.
2. Положи файл в папку `books/`.
3. Допиши имя файла в `books/index.json`:
   ```json
   ["sample.json", "mary-poppins.json"]
   ```
4. Подними версию в `sw.js` (`const VERSION = 'reader-v2'`), иначе Safari отдаст старый кэш.

Формат файла книги:

```json
{
  "id": "mary-poppins",
  "title": "Mary Poppins",
  "author": "P. L. Travers · Elementary",
  "level": "A2",
  "chapters": [
    { "title": "Chapter 1. The East Wind", "text": "Абзац.\n\nСледующий абзац." }
  ]
}
```

Тексты учебников под копирайтом, поэтому в репозиторий их лучше не выкладывать публично — либо держи книги только в браузере через импорт, либо сделай репозиторий приватным (тогда Pages доступны на платном тарифе).

## Что откуда берётся

| Что | Источник | Нужна сеть |
|---|---|---|
| Перевод предложения и слова | Google Translate (открытая веб-точка), запасной — MyMemory | да |
| Транскрипция, значения, аудио | dictionaryapi.dev | да |
| Произношение, если аудио нет | встроенный синтез речи iOS | нет |
| Словарь, прогресс, свои книги | localStorage | нет |

Ключи и регистрация не нужны. У MyMemory есть суточный лимит для анонимных запросов — при активном чтении может закончиться, тогда перевод просто не подставится и его можно вписать руками.
