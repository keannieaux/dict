# Словарь — приложение для изучения английского на iPhone

Все файлы лежат в одной папке, ничего собирать не нужно.

| Файл | Зачем |
|---|---|
| `index.html` | разметка пяти разделов |
| `style.css` | оформление |
| `app.js` | вся логика |
| `a2.js` | отдельный модуль практики уровня A2 |
| `words.json` | ваш словарь — правите чаще всего |
| `a2.json` | темы, истории, упражнения на правила, письмо и видео для A2 |
| `grammar.json` | карточки правил |
| `links.json` | подборка внешних материалов |
| `sw.js` | офлайн-режим |
| `manifest.webmanifest`, `icon-*.png` | иконка и имя на экране «Домой» |

## Разделы

**Словарь** — поиск по слову и переводу, буквенный указатель справа, тап раскрывает
определение и пример. Кнопка «Произнести» читает слово вслух.

**Урок** — четыре слова за раз, каждое проходит три шага: знакомство → перевод с русского
на английский → сборка предложения из перемешанных слов. Приложение само решает, что
показать: сначала просроченные повторения, потом новые слова.

**Тест** — десять слов, направление на выбор: рус → англ, англ → рус или вперемешку.
Мелкие опечатки засчитываются, правильное написание всё равно показывается. В конце —
разбор всех ошибок.

**Правила** — десять грамматических тем с примерами и пояснением, почему именно так.

**Материалы** — ссылки на бесплатное чтение и видео по уровням CEFR.

**A2** — практика уровня A2: слова по темам с мини-тестами, короткие истории с вопросами
на понимание, упражнения на использование правил, письменные задания с черновиком
в браузере и подборка видео.

## Как работает повторение

За каждым словом закреплён «ящик» от 0 до 5. Правильный ответ переводит слово в
следующий ящик, ошибка возвращает в первый. Интервалы: 1, 3, 7, 16 и 35 дней.
Прогресс хранится в самом браузере на телефоне и никуда не отправляется.

Прогресс привязан к адресу сайта. Если смените адрес, счёт начнётся заново.
Очистка данных Safari тоже сотрёт прогресс — это единственное серьёзное ограничение
такого способа хранения.

## Публикация на GitHub Pages

1. Загрузите все файлы в репозиторий (**Add file → Upload files**).
2. **Settings → Pages**: Source — Deploy from a branch, ветка **main**, папка **/ (root)**.
3. Через минуту-две сайт открывается по адресу `https://ваш-логин.github.io/имя-репозитория/`.

## Установка на iPhone

Откройте адрес **в Safari**, кнопка «Поделиться» → **На экран «Домой»**.
Дальше приложение работает офлайн.

## Как добавлять слова

Правьте `words.json`:

```json
{
  "w": "слово",
  "lvl": "B1",
  "ipa": "/транскрипция/",
  "pos": "глаг.",
  "tr": "перевод",
  "def": "определение",
  "ex": "Пример из четырёх и более слов."
}
```

Несколько переводов пишите через запятую или точку с запятой — тест засчитает любой
из них. Пример нужен длиной хотя бы в четыре слова, иначе шаг сборки предложения
для этого слова пропускается.

Сортировка и указатель строятся сами, порядок записей в файле не важен.
После каждой правки меняйте `dict-v3` в первой строке `sw.js` на `dict-v4` и так далее.
Проверить файл на ошибки можно на jsonlint.com — забытая или лишняя запятая
встречается чаще всего.

## Проверка на компьютере

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`. Двойной клик по `index.html` не сработает:
браузер блокирует загрузку файлов с `file://`.

## Про озвучку

Используется встроенный синтезатор речи iOS, поэтому голос зависит от системы,
а не от приложения. Качество заметно улучшится, если поставить премиальный голос:
**Настройки → Универсальный доступ → Устный контент → Голоса → English**,
выбрать голос и дождаться загрузки. Приложение подхватит его само.
