# Словарь — приложение для изучения английского на iPhone

## Что залить в репозиторий

**Заменить:** `index.html`, `style.css`, `app.js`, `sw.js`
**Добавить:** `course.js`, `course.json`
**Удалить:** `a2.js` (вкладки A2 больше нет)
**Оставить как есть:** `words.json`, `grammar.json`, `links.json`, иконки, манифест
**Оставить, но не трогать:** `a2.json` — из него я буду брать тематические слова
для будущих юнитов. В приложении он пока не используется.

Файл `course.json` от Kimi перезаписывается новым — там теперь программа
English File Pre-Intermediate.

## Разделы

| Вкладка | Что делает |
|---|---|
| **Словарь** | поиск по слову и переводу, буквенный указатель, озвучка |
| **Курс** | юниты по программе учебника: слова, грамматика, текст, упражнения, видео |
| **Повтор** | интервальные карточки — приложение само выбирает, что пора повторить |
| **Тест** | десять слов, направление на выбор, разбор ошибок в конце |
| **Ещё** | справочник грамматики и ссылки на внешние материалы |

## Как устроен курс

Программа юнитов повторяет English File Pre-Intermediate (4-е изд.): та же
грамматика, та же лексика, тот же порядок. Тексты, слова и упражнения написаны
для приложения — материалы Oxford University Press не копируются.

Каждый юнит содержит:

- **карту урока** — что в 1A, 1B, 1C по книге;
- **12 слов** с транскрипцией, определением, примером и озвучкой;
- **2 правила** с разбором и примерами;
- **текст** на 120–150 слов со словариком и вопросами на понимание;
- **6 упражнений** на грамматику с объяснением каждого ответа;
- **видео** по теме на внешнем бесплатном ресурсе.

Слова юнита автоматически попадают в общий словарь: их спрашивают «Повтор» и
«Тест». Полоска на карточке юнита показывает, сколько слов из него уже выучено
(слово считается выученным с четвёртого правильного ответа подряд).

Готовы юниты 1 и 2. Остальные добавляются в `course.json` тем же форматом.

## Как добавить свой юнит

В массив `units` файла `course.json`:

```json
{
  "n": 3,
  "title": "Название по-русски",
  "goal": "Чему учит юнит, одной фразой.",
  "map": [{ "id": "3A", "g": "грамматика", "v": "лексика" }],
  "words": [{ "w": "", "lvl": "B1", "ipa": "//", "pos": "", "tr": "", "def": "", "ex": "" }],
  "rules": [{ "t": "", "body": "", "ex": [["пример", "почему так"]] }],
  "text": {
    "title": "", "body": "",
    "glossary": [["word", "перевод"]],
    "questions": [{ "q": "", "options": ["", "", ""], "a": 0, "why": "" }]
  },
  "drills": [{ "prompt": "", "options": ["", "", ""], "a": 0, "why": "" }],
  "video": { "n": "", "u": "https://", "d": "" }
}
```

`a` — номер правильного варианта, считая с нуля. Пример у слова должен быть
не короче четырёх слов, иначе шаг сборки предложения пропускается.

## Как работает повторение

За каждым словом закреплён «ящик» от 0 до 5. Правильный ответ переводит слово в
следующий, ошибка возвращает в первый. Интервалы: 1, 3, 7, 16 и 35 дней.
Прогресс хранится в браузере телефона и привязан к адресу сайта: смените адрес
или очистите данные Safari — счёт обнулится.

## Публикация и установка

1. Загрузите файлы в репозиторий (**Add file → Upload files**).
2. **Settings → Pages**: ветка **main**, папка **/ (root)**.
3. Откройте адрес **в Safari** → «Поделиться» → **На экран «Домой»**.

**После каждой правки** меняйте номер версии в первой строке `sw.js`
(`dict-v7` → `dict-v8`). Иначе iPhone покажет старую сохранённую копию.

## Проверка на компьютере

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000`. Двойной клик по `index.html` не сработает.

## Про озвучку

Голос берётся из iOS. Чтобы он звучал живее, поставьте премиальный:
**Настройки → Универсальный доступ → Устный контент → Голоса → English**.
